## 结构校验

本地已执行官方校验。以下为可移植的复现方式：先将 `$skillCreatorDirectory` 设置为本机官方 skill-creator 的实际目录，再在项目根目录运行（该工具不包含在本项目中）：

```powershell
python -X utf8 (Join-Path $skillCreatorDirectory 'scripts/quick_validate.py') './skills/make-knowledge-cards'
```

输出：`Skill is valid!`，退出码为 0。

首次直接运行时，Windows 的 Python 默认使用 GBK，读取 UTF-8 的 SKILL.md 出现 `UnicodeDecodeError`。通过 Python 的 `-X utf8` 开关运行原版校验脚本后通过，没有修改官方脚本。初始化工具生成的中文 openai.yaml 也已从 GBK 转存为 UTF-8，并另外核对 YAML 字段与中文内容。
